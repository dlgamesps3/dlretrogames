# DL SERVIDOR — Site de jogos retrô

## Como publicar no GitHub Pages
1. Extraia o ZIP no seu celular ou computador.
2. Entre no GitHub e crie um repositório público chamado `dl-servidor`.
3. Envie **todo o conteúdo de dentro da pasta** `DL-SERVIDOR-SITE` para a raiz do repositório (não envie só o ZIP).
4. Confirme que `index.html` ficou na raiz, junto das pastas `css`, `js`, `img` e `pages`.
5. Abra Settings → Pages.
6. Em Build and deployment, escolha `Deploy from a branch`, branch `main` e pasta `/ (root)`, depois Save.
7. Aguarde a publicação e abra o endereço informado pelo GitHub Pages.

## Estrutura
- `index.html`: página inicial.
- `css/style.css`: estilos de todas as páginas.
- `js/main.js`: pesquisa e filtros do catálogo.
- `img/capas/`: capas ilustradas originais em SVG.
- `img/consoles/`: ilustrações dos consoles e banner.
- `pages/jogos/`: uma página individual para cada jogo.

## Sobre as imagens
As capas incluídas são artes gráficas originais feitas para este projeto, com título e elementos ilustrativos. Não são capas oficiais dos jogos. Para adicionar imagens suas, salve-as na pasta correspondente e atualize o caminho no HTML.

## Importante
O site é um catálogo informativo. Não inclui ROMs, BIOS ou downloads de jogos protegidos por direitos autorais.
